内部内容发表 / PROTOCOL 01

让文本
产生后果。

CONTENT IS NOT TRAFFIC.

这里不生产可滑过、可遗忘、只为算法停留率存在的内容。Ateamism 发表能够穿透理论、技术、文化与组织实践之间隔离墙的作品：它们必须带着问题进入现实，并留下新的行动接口。

01

理论 / THEORY

哲学、社会理论、政治经济学、精神分析、符号学与控制论。我们寻找能够暴露规则隐蔽语法的文本。

02

翻译 / TRANSLATION

译介尚未进入中文思想现场的重要文本，并说明术语选择、语境冲突与介入理由。

03

文化 / CULTURE

动画、游戏、摇滚、网络与亚文化现场。拒绝把它们处理为消费清单，而要揭示其中的组织潜能。

04

实验 / PROTOTYPE

组织方案、媒体装置、数字工具和未完成的现实原型。它们可以粗糙，但必须携带赌注。

EDITORIAL AXIOMS / 编辑公理

Ⅰ

拒绝把理论
降格为品味。

引用谁、喜欢谁、站在哪一边，都不能替代论证。理论必须产生区分、方法和后果。

Ⅱ

拒绝安全的
激进姿态。

真正的激进不是扩大音量，而是发现支配现实的隐藏公理，并提出可以被检验的替代结构。

Ⅲ

让异常成为
生产能力。

不被现成学科、身份和媒介格式收编的经验，不是噪音，而是新理论最先出现的位置。

SELECTION MATRIX / 选择矩阵

我们如何判断
一件作品。

我们不寻找“正确立场”的证明书，而寻找能够改变问题结构的作品。以下六项不是评分表，而是对文本施加压力的方向。

01

问题强度

不是重复一个已知答案，而是迫使既有语言暴露它无法处理的对象。

02

概念精度

拒绝术语堆积。每一个理论概念都必须说明它切开什么、连接什么。

03

材料密度

论证需要文本、历史、技术或现场材料支撑，而不是只依赖姿态与情绪。

04

现实接口

作品必须指出它如何进入组织、媒介、教育、文化生产或日常实践。

05

形式风险

允许混合论文、档案、图像、代码与叙事，只要形式本身承担思想任务。

06

不可替代性

如果文本可以被任何流行文章替代，它就还没有抵达 Ateamism。

OPEN DOSSIERS / 当前征集

正在打开的
思想战线。

DOSSIER A

超政治之后

孤立个体、数字动员、组织真空，以及集体行动如何重新获得持续时间。

DOSSIER B

机器与知识劳动

生成式 AI、自动化、教育和创作工具正在重写谁有资格生产知识。

DOSSIER C

欲望的基础设施

精神分析不只是解释主体，而是诊断平台、消费、身份与服从如何组织欲望。

DOSSIER D

亚文化不是货架

动画、游戏、摇滚与网络共同体如何保存尚未制度化的新感性和组织技术。

EDITORIAL PIPELINE

一条信号如何
变成公开事件。

01

信号接收

确认材料、作者说明与可公开范围。

02

结构诊断

编辑判断问题、论证、材料与形式是否构成真正的思想装置。

03

对抗编辑

不是润色，而是暴露薄弱公理，要求作者推进到更危险、更精确的位置。

04

发表与延伸

文本上线后进入专题、讨论、翻译或项目原型，继续产生后果。

通常在 14 天内确认是否进入编辑流程。所有修改建议都服务于增强作品，而不是把差异磨平。

SUBMISSION / SIGNAL

发送一个无法被安全消化的东西。

  1. 用 150—300 字说明你的文本要撞碎什么。
  2. 附上正文、译稿、项目原型或能够证明其必要性的材料。
  3. 邮件标题：［ATEAMISM SIGNAL］标题 / 类型。
  4. 允许未完成，但必须说明理论赌注、现实对象与下一步实验方向。
